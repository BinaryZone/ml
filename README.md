# 机器学习原理
## 一、线性回归
模型：$f(x) = w^{T}x + b$  
损失函数（残差平方和）：$J(w) = \sum_{i=1}^{n}(f(xi)-y_i)^2$  
参数求解：
1. 穷举法
2. 最小二乘法
利用损失函数对参数求偏导，令倒数为0进行参数求值
3. 梯度下降  
公式：$w=w - a\frac{\partial J(w)}{\partial w}$  
其中a为学习率
## 二、逻辑回归
模型：$g(X) = \frac{1}{1 + e^{-(w^TX + b)}}$
常用的激活函数：  
1. sigmoid函数：$g(z) = \frac{1}{1 + e^{-z}}$
